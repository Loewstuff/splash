# splash

A clean, professional yet light-hearted and funny **Coming Soon** splash page.

Single-file, production-ready, fully responsive HTML page with a cute golden retriever hero image, warm gold accents, subtle animations, and a working "Get notified" email signup form (placeholder).

## What's included

- **`index.html`** — Everything you need in one file:
  - Photorealistic happy golden retriever hero
  - Large bold "Coming Soon" + exact tagline: *"Pawsitively fetching something awesome..."*
  - Elegant "Get notified" form with vanilla JS success state
  - Modern minimalist design, excellent typography, warm gradient background
  - Fully responsive (mobile + desktop)
  - Accessible + fast loading
  - Clear comments for easy customization (no coding experience required)

- **`PROMPT.md`** — A strong, reusable prompt you can copy and paste into any LLM (Claude, GPT, Grok, etc.) to regenerate or customize this exact page **without writing any code yourself**.

## Quick start

1. Open `index.html` directly in any browser (double-click on Windows/macOS).
2. To use on your domain: upload `index.html` (and optionally a self-hosted image) to your web root.
3. Customize:
   - Search for "Pawsome" and replace with your brand
   - Replace the hero image URL (recommendations in PROMPT.md)
   - Update footer copyright year and links
   - (Optional) tweak colors in the CSS `:root`

## Image recommendations

For the best results, replace the placeholder image with a high-quality, self-hosted photo:

- Pexels: https://www.pexels.com/search/golden%20retriever/
- Unsplash: https://unsplash.com/s/photos/golden-retriever
- Pixabay: https://pixabay.com/images/search/golden%20retriever/

Download the highest resolution version, optimize it, and update the `<img src>` in `index.html`.

## Regenerating / customizing the page

See `PROMPT.md` — it contains the complete detailed prompt used to create this. Paste it into any capable AI and describe your desired changes.
